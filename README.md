# Zencore

A lightweight Windows 10/11 application for system, privacy, network, and performance optimization.

![Platform](https://img.shields.io/badge/Windows-10%2F11-0078D4?style=flat-square&logo=windows)
![.NET](https://img.shields.io/badge/.NET-8.0-512BD4?style=flat-square&logo=dotnet)
![Edition](https://img.shields.io/badge/Free_Edition-Active-22c55e?style=flat-square)
![Premium](https://img.shields.io/badge/Premium-Coming_Soon-e11d48?style=flat-square)

## Current Availability (v3.0.3)

- **Free Edition (Active)** — 50 curated core system tweaks + Cleaner, Startup Manager, Services, Network diagnostics, Privacy Styler, Debloat, Applications, and Monitor.
- **Zencore Premium (Coming Soon)** — Extended 455+ tweaks and GPU presets are currently marked **Coming Soon** across the app and [zencore.lol](https://zencore.lol). Only Free features are active right now.

## Installation

1. Download **Zencore-Setup-v3.0.3.exe** from [Releases](../../releases/latest)
2. Run the installer (Win 10/11, x64)
3. Launch **Zencore**

## Requirements

- Windows 10 / 11 (64-bit)
- .NET 8.0 Desktop Runtime (bundled in release build)
